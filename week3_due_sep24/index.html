Different Outcomes

Reflection

I started by selecting a small patch from the reference image rather than trying to recreate the entire composition. I noticed repeated circles, directional triangular forms, and intersecting lines, so I reduced the patch into those three basic shapes.

On paper, I experimented with moving, scaling, and rotating the shapes. In p5.js, I used translate(), rotate(), random(), and mouse interaction so that parts of the composition change when the canvas is clicked.

Some elements stay fixed while others change. I liked this because the result still keeps some connection to the original patch instead of becoming completely random.
