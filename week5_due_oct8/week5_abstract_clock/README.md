# Time Garden — Interactive Abstract Clock

## Concept

For this assignment, I wanted to explore time as something that changes and grows rather than something that is simply counted. I designed an interactive garden where the passage of time affects the environment, while the user can add to it.

## How It Works

I used three p5.js time functions:

- `hour()` changes the background between day and night.
- `minute()` controls the size of the flowers.
- `second()` controls their rotation.

I also added mouse interactions. Moving the cursor creates a light that follows the mouse, while clicking plants another flower in the garden.

## Process

I began with the idea of a flower representing time through growth. I then expanded it into an interactive environment by adding multiple flowers and mouse controls. I used repeated ellipses to create petals and a custom function to draw each flower.

## Reflection

The design explores how a clock can represent time without traditional numbers or hands. The environment follows the actual time, but the user can also influence what appears on the screen. This creates a contrast between time passing independently and the changes we choose to make within it.
